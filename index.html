Подключить сессию Notion

Вставьте cURL из браузера, где вы уже вошли в Notion.

Где взять нужный cURL

  1. Откройте Notion в Chrome или Edge и войдите в нужный аккаунт и workspace.
  2. Нажмите F12 или Ctrl + Shift + I. Выберите вкладку Network («Сеть») и фильтр Fetch/XHR.
  3. В поле фильтра введите getInferenceTranscriptsForUser. В Notion AI откройте список / историю чатов. Если запрос не появился, обновите страницу с открытым Network и снова откройте историю.
  4. Найдите запрос POST /api/v3/getInferenceTranscriptsForUser со статусом 200. Нажмите правой кнопкой → Copy → Copy as cURL (bash). Если есть только Copy as cURL, он тоже подойдёт.
  5. Вставьте скопированную команду целиком в поле ниже и нажмите «Проверить и подключить».

Также подойдут getInferenceTranscriptsUnreadCount или syncRecordValuesSpaceInitial. Нужен запрос к app.notion.com/api/v3/ с cookies. Запрос Google Translate или загрузка JS-файла не подойдёт. Команду не нужно запускать в терминале.

Сохранённые сессии

Меньше число — выше приоритет. После изменения нажмите «Сохранить приоритеты». «В автопуле» включает профиль в автоматический выбор. У каждой сессии выберите агентный чат кнопкой в заголовке истории.

Клиент извлечёт данные сессии и проверит доступ к чатам. После успешной проверки сессия сохранится локально для следующего запуска.

Подключение API и MCP

Для OpenCode и других клиентов. Ключ коннектора не содержит cookies Notion.

Модель notion-auto использует приоритеты профилей. Прочитать список алиасов можно через GET /v1/models. Текстовый API не поддерживает локальные tool calls; для инструментов OpenCode используйте MCP.
